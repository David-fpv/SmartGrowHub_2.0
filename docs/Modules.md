# Модули управления

> _Документ сгенерирован с помощью ИИ. При расхождении с поведением прошивки приоритет за кодом._

Модули регистрируются в `setup()` через `modules.AddSetting(...)`. Настройки автоматически сохраняются в LittleFS и восстанавливаются при перезапуске.

---

## Регистрация модуля в коде

```cpp
// setup() в main.cpp
modules.AddSetting(Setting(ModuleType::DayLight, SettingMode::Off, dayLight, 12));
modules.load(); // восстановить состояние из LittleFS
```

Аргументы `Setting`:

| Аргумент | Описание |
|---|---|
| `ModuleType` | Тип модуля |
| `SettingMode` | Начальный режим (только если нет сохранённого файла) |
| `function` | Функция управления, вызывается каждые 100 мс |
| `limit` | Максимальное количество единиц расписания |

---

## Список модулей

| Тип (`type`) | Описание | Пин | Макс. расписаний |
|---|---|---|---|
| `led` | Светодиод / индикатор | GPIO 2 | 4 |
| `dayLight` | Лампы дневного освещения | TRANSISTOR_1 (GPIO 19) | 12 |
| `uvLight` | УФ-лампы | TRANSISTOR_2 (GPIO 18) | 12 |
| `heater` | Нагреватель | TRANSISTOR_3 (GPIO 4) | 10 |
| `humidifier` | Увлажнитель воздуха | TRANSISTOR_7 (GPIO 26) | 10 |
| `fan` | Вентилятор | TRANSISTOR_5 (GPIO 14) | 4 |
| `waterPump` | Насос полива | TRANSISTOR_6 (GPIO 27) | 4 |
| `airFlap` | Вентиляционная заслонка (серво) | GPIO 23 | 10 |
