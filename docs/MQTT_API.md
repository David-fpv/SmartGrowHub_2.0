## 1. Топики

| Топик                  | Направление    | Описание                                  |
|------------------------|----------------|-------------------------------------------|
| `/Gomel/Tar/sensors/`  | ESP32 → клиент | Телеметрия сенсоров, каждые 30 с          |
| `/Gomel/Tar/modules/`  | Клиент → ESP32 | Команды управления модулями и расписанием |
| `/Gomel/Tar/response/` | ESP32 → клиент | Ответ на каждую принятую команду          |

> Топики переопределяются через `config.json`: поля `topic_sensors`, `topic_modules`, `topic_response`.

---

## 2. Данные сенсоров

ESP32 публикует JSON в топик `topic_sensors` каждые 30 секунд.

```json
{
  "device_id": "A0001",
  "data": [
    { "SensorId": 1, "Type": "airTemperature", "Value": 22.5, "Unit": "C" },
    { "SensorId": 2, "Type": "airHumidity",    "Value": 58.3, "Unit": "%" }
  ]
}
```

Набор сенсоров в сообщении соответствует зарегистрированным в `setup()`. Полный список сенсоров — в [Sensors.md](Sensors.md).

## 3. Команды управления модулями

Все команды отправляются в топик `topic_modules` в формате JSON.

### Структура

```json
{
  "device_id":  "A0001",
  "message_id": "01JKY5E122HBQSZKXMF0F7HR44",
  "type":       "<тип модуля>",
  "mode":       "<режим>",
  "action":     "<действие>",
  "schedule_unit": { ... }
}
```

### Поля

| Поле            | Тип    | Описание                                                       |
|-----------------|--------|----------------------------------------------------------------|
| `device_id`     | string | Идентификатор устройства (должен совпадать с прошивкой)       |
| `message_id`    | string | Уникальный ID сообщения; рекомендуется формат [ULID]          |
| `type`          | string | Тип модуля (см. [раздел 5](#5-типы-модулей-type))             |
| `mode`          | string | Режим работы (см. [раздел 4](#4-режимы-работы-mode))          |
| `action`        | string | Операция над расписанием: `"add"`, `"delete"` или `"none"`    |
| `schedule_unit` | object | Единица расписания; пустой объект `{}` при `"action": "none"` |

[ULID]: https://github.com/ulid/spec

### Правило: одно сообщение — одна задача

| Цель                        | `mode`                                         | `action`    |
|-----------------------------|------------------------------------------------|-------------|
| Сменить режим               | `"off"` / `"on"` / `"weekly"` / `"daily"`     | `"none"`    |
| Добавить единицу расписания | `"none"`                                       | `"add"`     |
| Удалить единицу расписания  | `"none"`                                       | `"delete"`  |
| Удалить все единицы         | `"none"`                                       | `"clearAll"` |

> Смешивать изменение режима и операции с расписанием в одном сообщении **нельзя**.

---

## 4. Режимы работы (`mode`)

| Значение   | Описание                                                                     |
|------------|------------------------------------------------------------------------------|
| `"off"`    | Модуль выключен                                                              |
| `"on"`     | Модуль включён постоянно                                                     |
| `"weekly"` | По расписанию с учётом дня недели (`DD` в интервале = `01`–`07`)            |
| `"daily"`  | По расписанию каждый день (поле `DD` в интервале игнорируется)              |
| `"none"`   | Режим **не изменять** — используется при операциях только с расписанием     |

---

## 5. Типы модулей (`type`)

| Значение `type` | Описание                        | Макс. `schedule_unit` |
|-----------------|---------------------------------|-----------------------|
| `"led"`         | Светодиод / индикатор           | 4                     |
| `"dayLight"`    | Лампы дневного освещения        | 12                    |
| `"uvLight"`     | УФ-лампы                        | 12                    |
| `"heater"`      | Нагреватель                     | 10                    |
| `"humidifier"`  | Увлажнитель воздуха             | 10                    |
| `"fan"`         | Вентилятор                      | 4                     |
| `"waterPump"`   | Насос полива                    | 4                     |
| `"airFlap"`     | Вентиляционная заслонка (серво) | 10                    |

Физические пины и регистрация модулей — в [Modules.md](Modules.md).

## 6. Управление расписанием

### Добавить единицу расписания

```json
{
  "device_id":  "A0001",
  "message_id": "01JKY5E122HBQSZKXMF0F7HR44",
  "type":       "led",
  "mode":       "none",
  "action":     "add",
  "schedule_unit": {
    "schedule_unit_id": "01JKY5E122ASDF098080ASD8",
    "kind":     "power",
    "interval": { "start": "01T06:00", "end": "01T22:00" },
    "quantity": { "magnitude": 80, "unit": "%" }
  }
}
```

### Удалить единицу расписания

Для удаления достаточно передать только `schedule_unit_id`:

```json
{
  "device_id":  "A0001",
  "message_id": "01JKY5E122HBQSZKXMF0F7HR55",
  "type":       "led",
  "mode":       "none",
  "action":     "delete",
  "schedule_unit": {
    "schedule_unit_id": "01JKY5E122ASDF098080ASD8"
  }
}
```

## 7. Формат `schedule_unit`

```json
{
  "schedule_unit_id": "01JKY5E122ASDF098080ASD8",
  "kind":     "power",
  "interval": { "start": "01T06:00", "end": "07T22:00" },
  "quantity": { "magnitude": 75, "unit": "%" }
}
```

### Поле `kind`

| Значение   | Описание                                                                  |
|------------|---------------------------------------------------------------------------|
| `"power"`  | Задать мощность напрямую (`magnitude` = 0–100%)                          |
| `"prefer"` | Поддерживать значение среды (`magnitude` = целевое, напр. `22` для `"C"`) |

> `"prefer"` недоступен для `led`, `fan`, `airFlap`.

### Поле `interval` — формат `"DDThh:mm"`

```
"DDThh:mm"
  ││  └── минуты (00–59)
  │└───── часы   (00–23)
  └────── день   (01=пн … 07=вс)
```

| Режим      | Роль поля `DD`                                              |
|------------|-------------------------------------------------------------|
| `"weekly"` | День недели: `01`=пн, `02`=вт, … `07`=вс. **Обязателен**  |
| `"daily"`  | Игнорируется — интервал повторяется каждый день             |

### Поле `quantity`

| Поле        | Тип    | Описание                                              |
|-------------|--------|-------------------------------------------------------|
| `magnitude` | int    | Числовое значение (0–100 для `%`, градусы для `"C"`) |
| `unit`      | string | `"%"` — проценты, `"C"` — градусы Цельсия            |

## 8. Ответ устройства

На каждую команду ESP32 публикует ответ в топик `topic_response`:

```json
{
  "device_id":  "A0001",
  "message_id": "01JKY5E122HBQSZKXMF0F7HR44",
  "code":       1
}
```

### Коды ответа

| Код  | Описание                                                                               |
|------|----------------------------------------------------------------------------------------|
| `2`  | Успешно: операция с `schedule_unit` выполнена (`add` / `delete`)                      |
| `1`  | Успешно: режим (`mode`) изменён                                                        |
| `-1` | Ошибка: не удалось изменить режим                                                      |
| `-2` | Ошибка: операция с `schedule_unit` не выполнена (не найден, лимит, неизвестный `action`) |
| `-3` | Ошибка: неверный `device_id` или неизвестный / неактивный тип модуля                  |
| `-4` | Ошибка: JSON не разобран                                                               |

## 9. Примеры

### Включить LED

```json
{
  "device_id": "A0001", "message_id": "01JKY5E100000000000000001",
  "type": "led", "mode": "on", "action": "none", "schedule_unit": {}
}
```

### Перевести LED в режим Daily и добавить расписание 80% с 06:00 до 22:00

```json
{ "device_id": "A0001", "message_id": "01JKY5E100000000000000002",
  "type": "led", "mode": "daily", "action": "none", "schedule_unit": {} }
```
```json
{
  "device_id":  "A0001", "message_id": "01JKY5E100000000000000003",
  "type": "led", "mode": "none", "action": "add",
  "schedule_unit": {
    "schedule_unit_id": "01JKY5E133HBQS0000000001",
    "kind": "power",
    "interval": { "start": "01T06:00", "end": "01T22:00" },
    "quantity": { "magnitude": 80, "unit": "%" }
  }
}
```

### Удалить все единицы расписания модуля

```json
{
  "device_id": "A0001", "message_id": "01JKY5E100000000000000005",
  "type": "led", "mode": "none", "action": "clearAll", "schedule_unit": {}
}
```

### Нагреватель: поддерживать 22°C пн–пт с 06:00 до 22:00 (Weekly)

```json
{
  "device_id":  "A0001", "message_id": "01JKY5E100000000000000004",
  "type": "heater", "mode": "none", "action": "add",
  "schedule_unit": {
    "schedule_unit_id": "01JKY5E133HBQS0000000002",
    "kind": "prefer",
    "interval": { "start": "01T06:00", "end": "05T22:00" },
    "quantity": { "magnitude": 22, "unit": "C" }
  }
}
```
