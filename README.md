# SmartGrowHub 2.0

> _Документ сгенерирован с помощью ИИ. При расхождении с поведением прошивки приоритет за кодом._

Контроллер теплицы на базе ESP32 (PlatformIO / Arduino). Управляет освещением, климатом и поливом по расписанию через MQTT.

---

## Модули управления

| Модуль | Описание |
|---|---|
| `led` | Светодиод / индикатор |
| `dayLight` | Лампы дневного освещения |
| `uvLight` | УФ-лампы |
| `heater` | Нагреватель |
| `humidifier` | Увлажнитель воздуха |
| `fan` | Вентилятор |
| `waterPump` | Насос полива |
| `airFlap` | Вентиляционная заслонка (серво) |

Пины, лимиты расписания и регистрация в коде — в [docs/Modules.md](docs/Modules.md).

---

## Сенсоры

| Сенсор | Аппаратура |
|---|---|
| Температура воздуха | BME280 (I2C) |
| Влажность воздуха | BME280 (I2C) |
| Атмосферное давление | BME280 (I2C) |
| Высота растения | HC-SR04, ультразвук (GPIO 33/25) |
| Освещённость | Фоторезистор, аналог (GPIO 34) |
| Температура почвы | NTC термистор, аналог (GPIO 35) |
| Влажность почвы | Аналоговый датчик (GPIO 32) |

Также доступен `randomNumber` — генератор случайных чисел для тестирования MQTT без реального железа.

Подробнее — в [docs/Sensors.md](docs/Sensors.md).

---

## Режимы работы

- **off** — модуль выключен
- **on** — включён постоянно
- **weekly** — по расписанию с учётом дня недели
- **daily** — по расписанию каждый день

Управление через MQTT. Настройки сохраняются в LittleFS и восстанавливаются после перезапуска.

---

## Быстрый старт

1. Отредактировать `data/config.json` (WiFi, MQTT брокер)
2. Загрузить файловую систему: **PlatformIO → PROJECT TASKS → pico32 → Platform → Upload Filesystem Image**
3. Прошить устройство, открыть Serial Monitor (9600 бод)
4. Раскомментировать нужные модули и сенсоры в `setup()` → [src/main.cpp](src/main.cpp)
